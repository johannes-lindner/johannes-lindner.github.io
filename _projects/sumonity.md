**SUMONITY** is an open-source co-simulation framework that enables sub-microscopic traffic simulations. It is designed to bridge the gap between different simulation tools and provide a comprehensive platform for traffic research, automated vehicle testing, and traffic safety analysis.

### Key Features

- **Sub-microscopic Simulation:** Detailed modeling of individual road users with realistic behavior patterns
- **Pedestrian and Bicycle Modeling:** Specialized modules for vulnerable road users
- **Co-Simulation Capabilities:** Integration with multiple traffic simulation engines (SUMO, etc.)
- **Automated Vehicle Integration:** Support for testing autonomous vehicles in realistic traffic scenarios
- **Flexible Architecture:** Modular design allowing customization and extension

### Current Development

SUMONITY continues to evolve with ongoing improvements in pedestrian modeling, streamlined deployment, and enhanced integration capabilities. Recent updates include better support for passenger boarding simulations and improved computational efficiency for large-scale scenarios.

### Applications

The framework is used for various research applications including traffic safety analysis, automated vehicle validation and testing, infrastructure design evaluation, passenger behavior simulation, and traffic flow optimization.

### Getting Started

For more information about SUMONITY, visit the official repository or documentation. The framework is available as open-source software and welcomes contributions from the research community.
