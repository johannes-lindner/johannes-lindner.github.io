summary: >
  Existing SUMO (Simulation of Urban MObility)–Unity co-simulation tools typically use Unity only as a graphical layer, limiting simulation realism. Sumonity, an open-source interface linking SUMO and Unity via TraCI, instead controls each traffic agent in Unity using PID (Proportional-Integral-Derivative) longitudinal control and pure pursuit control for steering. Simulation tests showed close position tracking, with error near 0.5 meters and a 7-meter look-ahead distance minimizing lateral deviation during turns.
